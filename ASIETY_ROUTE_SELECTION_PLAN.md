## 1. The rule, stated once

> **Rule R (the only badge rule).**
> For every badge slot in every generated surface, the rendered status is a pure function of the
> **strongest admissible route** to **the claim that slot names**, computed in three levels:
>
> - **Level 0 — per claim: the route must assert the claim *as stated*.** A route is a route
>   to claim *C* only if its premises are exactly the premises *C* is asserted under. A
>   **conditional** route may never serve an unconditional claim, and serving a conditional
>   claim with an unconditional route is a *weakening* that G2 must approve explicitly. This is
>   not an ordering preference — it is a difference of proposition (the worked example is the
>   Asiety identification, §4). Selecting across it is the one form of laundering Rule R cannot
>   permit.
> - **Level 1 — per claim: strongest route.** Among all kernel declarations that *entail* the
>   named claim and pass every admissibility gate (§5), the selected route is the one with the
>   **fewest substantive axioms**; ties broken by fewest premises, then fewest compiled steps,
>   then canonical name. A free route therefore always beats a priced route to the same claim
>   *of the same conditionality*.
>   **A machine-proven contradiction of the named claim outranks every establishing route** —
>   a refutation settles a question that a derivation only answers.
> - **Level 2 — per slot: worst conjunct.** A slot that names several claims is badged on the
>   *least strong* of its per-claim routes (a conjunction is only as strong as its weakest
>   link), and the badge names **every** substantive axiom paid at that weakest tier.
>
> Consequences that are part of the rule, not exceptions to it:
>
> 1. Route selection may relocate a price to the slot that actually pays it. It may **never**
>    delete one (§7.3, the no-laundering invariant).
> 2. Selection changes **which** price is displayed, never **whether** there is one: if the
>    strongest route to a claim is still substantive, the slot still reads `⚠️ AXIOMATIC (…)`.
> 3. A `⊥`/`⊘`/collapse terminator is a *shape* verdict (derived by `refutation_kind`, 5478) and
>    is **not** interchangeable with a price. A slot whose claim is *refuted* renders the
>    refutation; a slot whose claim is *asserted* renders its price. Shape decides which
>    question the slot is asking; price decides how much the answer costs.
> 4. **A conditional route is never rendered as an unconditional `✅`.** If the winning tier rests
>    on premises, the slot reads `✅ PROVEN (conditional on …)` and names those premises. A badge
>    that hides the premise under which freedom was obtained is the defect class this plan
>    exists to remove, in a new costume.

Nothing else in the document may override R. Where an existing helper disagrees with R today
(e.g. `_GLANCE_RANK`'s permissive default, `_worst_badge`'s tie-breaking, `checks[0]`), the
helper is what changes.

## 2. Why the current code cannot implement R

| **A — class** | `classify_proof_edge` | 3984 | pure function of `(boundary, kind, subst_axioms × Tag:)`; `def`/`structure` short-circuits to `DEFINITIONAL` *before* the price is read |

B selects *strongest*, C selects *most expensive*. Both are correct for their own slot type and
mutually inconsistent for the same slot. There is no single selector, and no gate that compares

## 5. `select_route` — the one selector

```python
# scripts/build_deduction.py, new section above `classify_proof_edge`

_STRENGTH = ("CONTRADICTION",   # the named claim is machine-refuted  (⊥ / ⊘ / collapse)
             "COUNTERMODEL",    # the named claim is not derivable   (independent separation)
             "PROVEN",          # established, 0 substantive axioms
             "AXIOMATIC",       # established, at a named price
             "AXIOM",           # the claim IS a declared axiom
             "OPEN")            # nothing in the kernel

def verdict_of(proof) -> str:            # Shape decides the question; the price never does.
    """`_STRENGTH` class of one compiled proof about one claim."""
    if proof.boundary: return "COUNTERMODEL"
    if refutation_kind(proof) in ("⊥ CONTRADICTION", "⊘ DENIAL REFUTED",
                                  "COLLAPSE — INCOHERENT"): return "CONTRADICTION"
    cls = proof_claimed_class(proof, _CTX["node_map"])
    return {"PROVEN": "PROVEN", "PROVEN↑": "AXIOMATIC", "AXIOM": "AXIOM"}[cls]

def select_route(claim: ClaimShape, candidates: list[ProofIR]) -> list[ProofIR]:
    """Rule R. Returns the *winning tier* of routes: every admissible candidate
    at the best (least) substantive count, deterministically ordered.

    Admissibility — all of (1)-(5) required, else the candidate is not a route:
      (1) namespace is Γ's own. `COUNTERMODEL_NAMESPACES` (2648) + `is_countermodel_declaration`
          (2662) reject, with **no fallback to a model namespace**.
      (2) the conclusion ranges over Γ's own sorts (`Subject`, `Entity`, `Prop`, `State`,
          `Means`, …). A model-local binder (`∃ s : S, …`) is rejected — C559.
          **Tested against `conjuncts[].sorts`, never against `refs`.** `refs` is a flat
          bag: it proves a model-local constant is *mentioned*, not that the claim
          *ranges over* it, and 605 records have an `∃` conjunct whose sorts were
          empty. **EXCEPT** when the candidate is a
          `CONTRADICTION` (see the carve-out in §5.1 G1) — a countermodel is a
          legitimate *thing to assert* and illegitimate as a *route to a Γ claim*.
      (3) the conclusion **entails** `claim`. Exact structural match, with one
          documented licence: `claim.subclaims` may name individual conjuncts of a
          conjunction goal (that is what lets the Asiety identification detach from
          `asietic_summary`).
      (4) `countermodel_blocked` routes may only win when nothing else is admissible.
      (5) a declared ◈ stipulation keeps its marker (G4) — a stipulous `def` may be
          selected but may never render `✅`.

    Ordering inside a tier: (fewest substantive, fewest premises, fewest compiled steps,
    canonical full name). No tier may be empty: **no admissible candidate → SystemExit.**
    """
```

## 6. Precondition: a trustworthy conclusion shape

Rule R needs to know *which declarations are routes to the same claim*. §2.1 shows the current
extractors cannot answer that. Two changes, in this order.

### 6.1 `formal/goal_audit.json`, produced by a new `scripts/audit_goals.py`

Same pattern and same justification as `audit_footprints.py`: the shape of a declaration is
something the **kernel** knows exactly and a regex guesses.

A temp `import Logos` module runs under `lake env lean` and, for every declaration in
`formal/depgraph.json`, emits:

```json
{
  "Logos.AsieticChoice.asietic_summary": {
    "kind": "thm",
    "goal": "(∀ (s : Logos.Agency.Subject) (p : Prop), …) ∧ (∀ …) ∧ ∃ s p q, TrueChoice s p q",
    "goalTag": "app",
    "conjuncts": [
      {"quant": "forall", "sorts": ["…Subject", "…Prop"],
       "head": "->", "spine": "->(…ChoiceField/3(s,p,!(p)), ->(…ClaimsCorrect/2(s,p), …Chooses/3(s,p,!(…))))"},
      {"quant": "forall", "sorts": ["…Subject", "…Prop", "…Prop"],
       "head": "->", "spine": "->(…Chooses/3(s,p,q), …TrueChoice/3(s,p,q))"},
      {"quant": "exists", "sorts": ["…Subject", "…Prop", "…Prop"],
       "head": "…TrueChoice", "spine": "…TrueChoice/3(s,p,q)"}
    ],
    "hypothesis": [],
    "headSyms": ["->", "->", "…TrueChoice"],
    "quant": "mixed",
    "valueConjuncts": [], "valueHeads": [],
    "boundSorts": [], "binderFree": [],
    "refs": ["…Subject", "…Prop", "…TrueChoice"]
  }
}
```

The `hypothesis`, `boundSorts` and `binderFree` entries are `[]` **in this very record**, and
that is not an oversight in the sketch: `asietic_summary` is a three-way conjunction whose
`∀`-binders are consumed by the conjunction, so the reader — which peels only *leading*
binders — leaves them empty and its `∃`-conjunct's sorts carry the quantification instead. A
sketch that showed them populated here would invite exactly the misreading §13.3 warns about.
`Logos.BipolarityRetorsion.A18_is_independent_optional_semantic_premise` is the same shape with
the failure visible: `hypothesis == []`, `conjuncts[1].sorts == ["Exists"]`.

**`conjuncts` is the load-bearing field and it is *ordered***; `headSyms` and `quant` are
derived from it for display and must not be read as the shape (see §6.2). `hypothesis` is
**not** an inventory of premises — `Meta.forallTelescope` peels only leading binders, so a
premise under a conjunction is absent; §13.3 states this consequence for G1/G2 and
`test_goal_audit.py` asserts the A18 case by name.

`goal` is produced by **recursively stripping `Expr.forallE`/`mdata`/`letE` in Lean**, never by
splitting on `:` — so the `(s : Subject)` binder bug of §2.1 cannot recur, and the `let`
abbreviations a `by` block introduces do not hide a head. Guards, mirroring
`audit_footprints.py`: every audited declaration gets a record; every `Logos` constant appearing
in a goal must exist in the **environment** (not `depgraph.json`, which omits model-local
constants — their absence is the G1 signal); unbalanced brackets in a `thm`/`axiom` goal are
fatal, because that is the signature of a goal truncated at a pretty-printer line break;
`sorryAx` never appears.

**No mathlib, no new dependency** (`AGENTS.md`): the script uses `Lean.Environment.constants` and
`Lean.Expr` from core, exactly as the existing dep does.

### 6.2 `ClaimShape` and the entailment check, in Python

> **AMENDED 2026-09-30 — the version below as originally written is
> unimplementable and must not be coded.** It defined `ClaimShape` over a
> `frozenset` of `headSyms`. Measured against the artifact, that is blind for
> **4 698 of 6 397 records** (1 830 of them `thm`/`axiom`), whose `headSyms` are
> entirely connectives. C294 — the refutation both §4.1 item 2 and §8.2 make
> load-bearing — read as `{Not}`, indistinguishable from any other three-fold
> negation, so G2 would have declared it `INCOMPARABLE` and failed the build. And
> a `frozenset` **collapses 219** records' conjuncts, in **21** of them merging a
> `∀` with an `∃` — `asietic_summary` and C294 both among them. A set also cannot
> distinguish a conjunct list from a superset of one, which is exactly what G5
> (Level 2 `max`, "a conjunction is only as strong as its weakest link") needs.
> `headSyms` survives as a **display field only**.

```python
@dataclass(frozen=True)
class ConjunctShape:
    quant : str                    # "forall" | "exists" | "plain"
    sorts : frozenset               # Γ sorts this conjunct's quantifier binds
    head  : str                    # fully qualified head constant
    spine : str                    # depth-bounded structural signature

@dataclass(frozen=True)
class ClaimShape:
    conjuncts : tuple[ConjunctShape, ...]   # **ordered**; a frozenset is not a shape
    polarity  : str                          # "positive" | "separation" | "contradiction"
```

`entails(candidate, claim)` (6.2) accepts exactly two relations, both explicit:
`IDENTICAL` (same ordered conjunct list — quantifier, sorts, head and spine agree
modulo binder renaming) and `REFUTES` (`candidate` is a contradiction/separation
of `claim` under `refutation_kind`'s derived shape). Everything else is
`INCOMPARABLE` — and `INCOMPARABLE` is **not** admissible (G2). A conjunction slot
declares `subclaims=[…]` and the selector may serve each from a different route;
the slot's badge is the Level-2 `max` (G5).

`spine` is what lets `Not (P → Q)` be told from `Not (R → S)`; depth is bounded
(at 4, as in the audit) and the bound is part of the definition — a spine that is
`…` at the cut is `INCOMPARABLE`, never `IDENTICAL`. Two declarations stating one
claim under differently-*ordered* binders still produce different spines, because
spines name binders rather than indexing them; that is a **false negative**, and
false negatives are loud (`INCOMPARABLE` → G2 → build failure) rather than silent.
That trade is deliberate. A de-Bruijn `α`-equivalence fingerprint would close it
and is the natural successor if G2 turns out to be too noisy in practice.

This is deliberately stricter than `compare_routes`' concept-subset test (3891). That test is kept
for the narrative appendix (it reads GAPMAP-transcribed statuses there and is not badge-facing),
and is **not** reused for badges.

   the kernel verified. Proven by construction: the only inputs are `axiom_audit.json`,

2. **Refutation dominance** — the one place where "strongest" is not "cheapest". For any slot
   whose `ClaimShape.polarity` is `contradiction`/`separation`, `select_route` is restricted to
   `CONTRADICTION`/`COUNTERMODEL` candidates and a priced *establishing* route is **not
   admissible** (G2), so it can never occupy a refutation's badge. Conversely a `⊥` can never be
   selected for a `polarity="positive"` slot. The two directions are checked by one gate:
   `_lint_refutation_wiring` (6479) gains a half asserting `refutation_kind`-derived kinds and
   `_STRENGTH` verdicts never disagree on the same slot.

## 13. REFERENCE — interface facts that are not in the code

Interface facts about `formal/goal_audit.json` and the builder. Not history: each one is a
property a future change must code against, and none is inferable from reading the source.

1. **`goal_audit.json` is a flat `name -> record` map.** `kind` is `thm` | `axiom` | `def` |
   `opaque` — **`thm`, not `theorem`**. `parse_lean_sources` reads *Lean-source* kinds, which do
